# OctoAcme Project Management Process Docs

## Overview
Welcome to the OctoAcme project management documentation. These guides standardize how we run projects across the organization, from initial concept through retrospectives.

## Core Principles
- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has named roles with clear responsibilities
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning from all team members

## How to Use These Docs

### For New Team Members
1. Start with the [Project Management Overview](./octoacme-project-management-overview.md) to understand our framework
2. Review [Roles and Personas](./octoacme-roles-and-personas.md) to find your role and responsibilities
3. Explore the specific lifecycle phases relevant to current and upcoming projects

### For Project Kickoff
1. Use [Project Initiation](./octoacme-project-initiation.md) to validate the business need and create a one-pager
2. Follow [Project Planning](./octoacme-project-planning.md) to build your backlog and timeline
3. Reference [Risk Management & Communication](./octoacme-risks-and-communication.md) to identify and track risks

### For Ongoing Execution
1. Refer to [Execution and Tracking](./octoacme-execution-and-tracking.md) for day-to-day guidance
2. Use [Risk Management & Communication](./octoacme-risks-and-communication.md) for status updates and escalations
3. Prepare for release with [Release and Deployment](./octoacme-release-and-deployment.md)

### For Project Closure
1. Run a retrospective using [Retrospective and Continuous Improvement](./octoacme-retrospective-and-continuous-improvement.md)
2. Capture learnings and action items for future projects
